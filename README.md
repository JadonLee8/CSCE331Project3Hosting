## Dunsin Donuts Project 3
## Introduction
A Vite website running Svelte with a Go backend and a PostgreSQL database.

## Running application locally
```
npm i
npm run dev
```

## Building
Build artifacts for both frontend and backend application is in frontend/dist and backend/dist respectively. 
```
npm run clean # Optional
npm run build
```
